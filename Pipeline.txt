02 gene annotation
1.gene structure annotation
1) homologous sequence alignment
RepeatMasker(v4.1.1) -lib custom_repeats.lib -dir repeatmasker_out -pa 10 -xsmall genome.fa
RepeatProteinMask(v4.1.0) -noLowSimple -pvalue 0.0001 -lib transposon_proteins.fa genome.fa
2) predict from scratch: Build a library of repeats
ltr_finder(v1.07) -D 15000 -d 1000 -L 7000 -l 100 -p 20 -C -M 0.9 genome.fa > ltr_finder.out
build_lmer_table -sequence genome.fa -freq genome.lmer_table
RepeatScout(v1.0.5) -sequence genome.fa -output repeatscout.out -freq genome.lmer_table -l 50
BuildDatabase -name my_genome_db -engine ncbi genome.fa

trf(v4.09) genome.fa 2 7 7 80 10 50 500 -h -d
3) predict from the beginning
RepeatMasker(v4.1.1) -a -nolow -no_is -norna -parallel 1 -lib custom_repeats.fa -dir output_dir genome.fa
2.Gene structure annotation
1) homologous prediction
miniprot -t8 --gff miniprot/annot.gff evidence.fasta genome.fa > miniprot/alignments.out
2) denovo forecasts
augustus(v3.2.3) --species=human genome.fa > augustus/predictions.gff
glimmerhmm(v3.0.4) genome.fa -d /path/to/trained_model -g glimmerhmm/predictions.gff
athom(v2013.11.29) snap/predictions.zff -gene-stats > snap/predictions.gff

geneid(v1.4) -P /path/to/parameter_file.cfg -o predictions.gff genome.fa
3) transcriptome prediction: Aligned to assembly sequences
hisat2-build(v2.0.8) -p 8 genome.fa genome_index

4) transcriptome Prediction: Transcript Notes
stringtie(v2.1.6) sorted.bam -G genes.gtf -o transcripts.gtf -p 8
5) second-generation transcriptome splicing
Trinity(v2.1.1) --seqType fq --left left_1.fq,left_2.fq --right right_1.fq,right_2.fq --max_memory 20G --CPU 8 --output trinity_out
6) transcriptome prediction: Contrast to genome
Launch_PASA_pipeline.pl(v2.4.1) -c pasa_conf/conf.txt -C -R -g genome.fa -t transcripts.fasta --ALIGNERS blat,gmap --CPU 8
7) the three outcomes were integrated into a gene set
evidence_modeler.pl(v1.1.1) --genome genome.fa --weights weights.txt --gene_predictions gene_predictions.gff --protein_alignments protein_align.gff --transcript_alignments transcript_align.gff --output_file evm.out
8) final annotation
Launch_PASA_pipeline.pl(v2.4.1) -c pasa_conf/conf.txt -g genome.fa -t transcripts.fasta -A --annots_gff3 existing_annotations.gff3 --CPU 8
3.Gene function annotations

04 Calling SNPs using GATK
SNP calling using NGS data:
First intall BWA (v0.7.19), samtools (v1.4.0), GATK (v3.8) and annovar (v2013-05-20) software using conda
1.Mapping clean reads of individual sample onto genome sequence one by one:
bwa index genome.fa
bwa mem -t 20 -R '@RG\tID:RYP1ID\tSM:genome' genome fq1 fq2 | samtools view -@ 20 -bh - | samtools sort -@ 20 -T test -o bam.sample.file - 
2.Calling SNPs and InDels for individual sample one by one:
gatk HaplotypeCaller -R genome.fa –emit-ref-confidence GVCF -I bam.sample.file -O GVCF.sample.file
3.Megre GVCF files from all samles using GATK into one GVCF file and convert GVCF into VCF file:
gatk CombineGVCFs -R genome.fa -V GVCF.samlpe.vcf -V GVCF.samlpe1.vcf -V GVCF.samlpe2.vcf -V... -O vcf.multiple.file.gvcf
gatk GenotypeGVCFs -R genome.fa -V vcf.multiple.file.gvcf -O vcf.multiple.file.vcf
4.Filtered SNP VCF
vcftools --vcf vcf.multiple.file.vcf --recode --maf 0.05 --max-missing 0.5 --out filter.vcf
5.Annotate SNP function using ANNOVAR software:
gtfToGenePred.txt -genePredExt genome.gtf Database.dir/genome_refGene.txt
perl retrieve_seq_from_fasta.pl --format refGene --seqfile genome.fa genome_refGene.txt --out Database.dir/genome_refGeneMrna.fa
table_annovar.pl filter.vcf Database.dir/ -buildver genome  -out prefix -remove -protocol refGene -operation g -nastring . -vcfinput
